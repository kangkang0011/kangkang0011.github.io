# 不想上班 · 打工人抽卡模拟器

一个纯前端的原创抽卡模拟器：主题是「打工人」，玩法结构参考主流二次元抽卡游戏（限定祈愿、软保底、大保底、模拟充值、图鉴与统计）。

线上地址：https://kangkang0011.github.io/

## 特点

- **原创内容**：7 位五星打工人、12 位四星打工人、12 件办公用品，共 31 件收集品；名字、技能、台词全部自创，不涉及任何真实游戏、公司或人物。
- **程序化立绘**：每个角色的卡面由角色 id 推导出配色、光效角度与几何构图，不依赖任何外部图片素材，也不会有两张相同的立绘。
- **稀有卡演出**：抽到四星 / 五星时，卡片会先放大到屏幕中央展示（五星附带金色光芒），再平滑缩回它在结果中的位置。放大倍数会按视口自适应，保证整张卡完整可见。
- **真实保底机制**：五星基础 0.6%，第 74 抽起每抽 +6%，第 90 抽硬保底；五星 50% 概率为 UP，歪了之后下次必出 UP；四星 6%，10 抽内必出四星或以上。
- **模拟充值**：六档充值（含首充双倍）+ 打工人月卡（每日 90 工资）。**纯模拟，不涉及任何真实支付。**
- **数据面板**：出金率、平均出金抽数、UP 占比、分卡池统计、最近 400 条抽卡记录、图鉴收集进度。
- **成就系统**：30 项成就（24 项公开 + 6 项隐藏），覆盖祈愿次数、出金时刻（首次出金 / 双黄蛋 / 80 抽后出金 / 30 抽内出金）、图鉴收集与资源充值。隐藏成就未达成前在面板里只显示「???」，达成后才揭晓条件与奖励。达成后自动发放工资奖励并累计成就点，顶栏 🏆 查看全部进度。达成时从右侧滑入成就卡片，在稀有卡缩回结果格的那一刻就提示（不用等玩家关掉结果页），一次解锁 4 项以上会合并成一张汇总卡；其余提示统一显示在顶部中间。
- **背景鱼群**：12 种程序化绘制的鱼（咸鱼 / 金鱼 / 锦鲤 / 小丑鱼 / 河豚 / 热带鱼 / 带鱼 / 秋刀鱼 / 鲨鱼 / 鲸鱼 / 章鱼 / 灯笼鱼）在背景里游动，每条鱼的种类、体型、速度、游动方向与深度都是随机的，不加载任何图片；系统开启「减少动态效果」时自动不生成。
- **音效**：抽卡点击、三星 / 四星 / 五星各自的出金演出、稀有卡飞回落位、工资到账、充值、成就达成共 9 种音效。全部用 Web Audio 实时合成（振荡器 + 噪声 + 包络），不加载任何音频文件，设置里可一键关闭。
- **本地存档**：抽卡记录、保底计数、余额与充值记录存在浏览器 localStorage，可导出 / 导入 JSON。

## 目录结构

```

tools/sim.js        概率压测脚本
tools/audio-test.js 音效配方校验脚本
tools/achievement-audit.js 成就可达性审计脚本
```

## 本地运行

直接双击 `index.html` 即可游玩；也可以起一个本地服务：

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

## 验证概率

引擎与界面分离，可以用 node 直接压测，不需要浏览器：

```bash
node tools/sim.js 1000000
```

100 万抽的实测结果：

| 指标 | 实测 | 设计值 |
|---|---|---|
| 五星综合概率 | 1.596% | 约 1.6% |
| 四星综合概率 | 12.24% | 约 12.7% |
| 五星平均抽数 | 62.7 抽 | — |
| UP 占五星比例 | 66.4% | 66.7% |
| 最大出金抽数 | 89 抽 | ≤ 90（硬保底） |
| 大保底违约 | 0 次 | 必须为 0 |

脚本会逐项校验并在失败时以非 0 状态码退出，方便后续改动后回归。

## 验证音效

```bash
node tools/audio-test.js
```

用假的 AudioContext 跑一遍全部音效配方，并按浏览器规则校验（例如
`exponentialRampToValueAtTime` 的目标值必须为正数，否则真实浏览器会直接抛错），
同时验证静音开关确实不再产生音频节点。

## 验证成就可达性

```bash
node tools/achievement-audit.js 1000000
```

用真实引擎模拟大批量抽卡，再调用真实的成就判定逻辑，逐条检查「引擎驱动」的成就是否真的能达成。
这个脚本找出了 4 条原本永远无法达成的成就：

- 第 90 抽硬保底：软保底从第 74 抽起每抽 +6%，到第 89 抽单抽概率已超过 90%，实测 30 万抽中触发 0 次
- 连续 3 次 / 5 次歪卡：大保底机制下歪一次下次必为 UP，最长连续歪只能是 1
- 十连全是三星：四星保底卡死，最长连续三星为 9，全三星十连不存在

## 说明

本项目是纯娱乐的模拟器：所有角色、物品、文案均为原创；充值按钮只是界面演示，不会产生任何真实支付，也不会收集任何支付信息。
